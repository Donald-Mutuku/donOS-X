# donOS X

<img width="1855" height="970" alt="image" src="https://github.com/user-attachments/assets/9bf3f60a-d361-4ff8-afec-1215f54d8e53" />

<p>A web-based operating system built using HTML, CSS, JavaScript, pins, needles, prayers and coffee.</p>
<p>**Still massively WIP.** These are but the early stages of something big. Kinda big. Not very.</p>

<p>don OS X is my attempt at recreating the feel of 2000s desktops and the webcore aesthetic, with my personal twist of flat, bright pastel colours. It's a unique hybrid of multiple design styles, aiming to mimic the traditional curated feel of desktops without copying and pasting what has already been done.</p>

> Version 0.1 is live! Currently working apps are a basic Notepad and Paint app. Much more to come in the future!

## Features
- A classic monitor interface with overlayed effects to recreate the feeling of traditional CRT monitors
- Custom-made design language with key focus on uniqueness
- A Notepad app with the ability to create and save multiple notes, as well as edit existing ones.
- A Paint app with drawing, erasing, and fill functions and a reliable viewport, allowing users to create and save multiple drawings separately and even to locally save their creations.
